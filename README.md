# Health Explainer Interface Assets

Supporting assets for a health explanation interface. The repository currently contains ZIP archives with templates and input materials. It does not include a standalone application setup. Use the research-explainer repositories for application source and configuration.

[Angel Guechi portfolio](https://github.com/AngelGuechi)

## Repository contents

- `templates.zip`: interface templates and archived development material.
- `input.zip`: supporting input archive.

The archives have not been repackaged as a deployable release.
